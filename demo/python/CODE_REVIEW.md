# Python Code Guidelines & Standards

- **Type Annotations**: All function signatures must include explicit Python type hints (`str`, `int`, `dict`, etc.).
- **Code Style**: Adhere to PEP 8 naming conventions (snake_case for functions/variables, PascalCase for classes).
- **Docstrings**: Every module, class, and public function must have a clear docstring explaining purpose and parameters.
- **Error Handling**: Use explicit exceptions; avoid bare `except:` blocks.
- **Testing**: All new or modified functions must have accompanying unit tests.
